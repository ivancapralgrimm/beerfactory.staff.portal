### Загрузка с телефона

1. Распаковать ZIP в приложении «Файлы» на iPhone.
2. В GitHub открыть ветку **`r40.6-attestation-editor`**.
3. Заменить **один файл** `src/features/attestation/AttestationSettingsAdminPanel.tsx` на одноимённый файл из ZIP, сохранив путь.
4. Дополнительно (для регрессионной проверки) добавить новый файл `tests/attestation-create-ticket-feedback-v4-2.test.cjs` в `tests/`.
5. Не загружать `README_INSTALL_FROM_PHONE.md`, `MANIFEST_SHA256.json` и сам ZIP в репозиторий. `main` не трогать.

### Что исправлено
- Новый билет после нажатия «Добавить» оказывается первым, подсвечивается и прокручивается к карточке.
- Рядом с кнопкой «Добавить» есть подтверждение успешного создания и инструкция, что делать дальше.
- Если сервер сохранил билет, но обновление списка не удалось, интерфейс сообщает об **успешной записи**, а не выдаёт ложное «Не сохранено». Так пользователь не создаст дубликат.
- Ошибки пустого названия, дубликата и несохранённых настроек показываются там же, где вводится название.
- Проверяется, что только что созданный билет действительно появился в ответе редактора Supabase.
- Перенос новой карточки наверх только визуальный и не меняет порядок настроек/dirty-state.

### Полный сценарий после установки
1. «Управление персоналом → Аттестация → Настройки», написать уникальное имя в «Новый билет».
2. Нажать **«Добавить»**. Увидеть подтверждение и новую карточку сверху со статусом «Черновик».
3. Выбрать «Тип билета» и «Заведение», указать размер билета.
4. Добавить разделы и количество вопросов; нажать нижнюю кнопку **«Сохранить настройки»**.
5. Достаточно активных вопросов нужного типа и заведения? Открыть «Дополнительно» и нажать **«Включить категорию»**.
6. Проверить, что билет появился у сотрудника в «Знания → Аттестация» и проходит полный цикл.

Если выбрать **BeerBistro** или **BF/BB — Общий**, но в банке нет активных вопросов с подходящей привязкой, **активация корректно блокируется**. Сейчас исторические 334 вопроса по умолчанию помечены как BF. Чтобы новый BB/общий билет включился, администратор должен отметить соответствующие вопросы BB или «BF/BB — Общий» в редакторе вопросов и настроить достаточное количество групп по разделам.

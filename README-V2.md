# BeerFactory Unified V2

Готовый вариант редизайна Training по согласованному макету.

Главное:
- единый dark/gold стиль;
- Training как библиотека материалов;
- `article` и `note`;
- отдельный полноэкранный просмотр статьи;
- содержание для длинных материалов;
- фотографии с lightbox;
- поиск и категории;
- общий `styles.css`;
- общий `script.js`;
- структурированные данные в `training-data.json`.

Подробная установка: `INSTALL-TRAINING-V2.md`.
Визуальный референс: `training-v2-mockup.png`.

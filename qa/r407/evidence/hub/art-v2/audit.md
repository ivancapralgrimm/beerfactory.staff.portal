# Factory Run: материалы и персонаж

Продукт: небольшая сенсорная игра для команды BeerFactory внутри Hub. Характер: тёплый, заводской, игровой. Мир: пивоварня с деревом, кирпичом и медью. Насыщенные моменты: сама 3D-сцена и фирменная кружка. Подпись: персонаж в жилете BFStaff. Действующая оболочка «Тёплого зала» сохранена.

Unslop (Damir Sokolovsky, CC BY 4.0): найденные недостатки были в визуальном содержимом — ровные материалы без фактуры, простая цилиндрическая кружка, слабая читаемость фирменных деталей, сжатие тела при подкате. Исправлены оригинальными процедурными картами дерева/кирпича/меди/пены, детальной посудой и одеждой персонажа, позой без масштабирования тела. Цвета материалов объявлены в theme block. Текст, типографика, интервалы, Plump icons, оболочка, доступность кнопок и игровой сценарий не перепридуманы. Декоративные блики остаются внутри сцены, интерфейс не получил свечения или бесконечных анимаций.

Hallmark v2.0: app scope, playful, existing BFStaff theme. Source и реальный render-checker для Hub, запуска и активного рейса: 0 FAIL, 0 REFLEX, 0 WARN, 1 ANSWERED F4 в каждом. F4 относится к взаимоисключающим кнопкам различных фаз; это существующий ответ, не новый waiver. Render-checker получает точный DOM с настоящим браузерным снимком Canvas, а не нарисованный концепт; интерактивность проверяется отдельным browser suite.

При техническом саморевью объединённые модели препятствий переведены на кэш из четырёх типов, чтобы новая геометрия не создавалась на каждый следующий ящик/бочку. Текстуры принадлежат конкретному WebGL-контексту и освобождаются при выходе. CPU-кэш хранит один набор исходных карт. Независимый reviewer обнаружил и помог исправить рассинхронизацию движения карты пола с игровым расстоянием: смещение теперь использует фактический texture repeat, карта высоты синхронизирована с цветом.

До: `../hub-3d-390.png`, `../running-3d-390.png`. После: реальные PNG рядом с этим файлом. Авторские игровые карты не являются фотографическими сканами; графика остаётся стилизованной. FPS и энергопотребление физических телефонов команды не измерены. Проверки используют явные auth/data fixtures, не подтверждают production auth/RLS и не пишут в базы.

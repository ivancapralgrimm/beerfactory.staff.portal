# Hub / Factory Run: дизайн и проверки

Направление: игровой цех BeerFactory внутри действующего «Тёплого зала». Одна насыщенная сцена, спокойная оболочка, фирменная кружка и медь. Оформление остальных разделов сохранено.

Unslop (Damir Sokolovsky, CC BY 4.0): проверены интервалы 4px, тёплая нейтральная палитра, существующие Plump icons, краткие подписи, иерархия Geist, ширина мобильного экрана, состояния кнопок, реальная продуктовая сцена и функциональное движение. Ненужных обещаний, выдуманных отзывов/метрик, emoji-иконок и движения в статичной карточке нет. Авторство/лицензия самого навыка сохранены.

Hallmark v2.0: app scope, playful, existing BFStaff theme. Source и render checks Hub, готового рейса и активной игры: 0 FAIL, 0 REFLEX, 0 WARN, 1 ANSWERED F4. Source-анализ видит кнопки различных фаз одновременно; фактический интерфейс показывает запуск/продолжение только при остановке и паузу только во время рейса. Это отмечено в CSS, без Floor-waiver. Отчёты render-checker используют замороженный DOM реального приложения с изображением реально нарисованного Canvas; интерактивные сценарии проверены отдельно.

Исправлены обрезка развёрнутой помощи на 320×568 и продолжение игры под меню при клавиатурном открытии. Пауза навигации больше не возвращает фокус с «Разделов» в игру. Независимый reviewer повторил эти проверки.

Реальные скриншоты приложены. Результаты движка и браузера находятся в verification/browser-results/portal-regression. Production бизнес-данные, успешный вход настоящего сотрудника, RLS, физический Safari и FPS реальных телефонов этими проверками не подтверждаются.

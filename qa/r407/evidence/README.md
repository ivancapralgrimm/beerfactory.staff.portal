# Проверки приложения

Исполняемые проверки находятся в `../tests/`. Старые PNG/HTML/build-логи удалены из рабочего дерева; их можно восстановить из коммита `c72c6e0`. JSON с эталонной геометрией и исходники проверок сохранены. Некоторые исторические JSON/текстовые отчёты содержат пути к таким старым снимкам; это записи о прежнем запуске,не отсутствующие зависимости приложения. Скрипты заново создают каталоги/вывод.

Актуальный серверный релиз: `backend-release/`. Правила очистки: `docs/retention/README.md`. Новые screenshots/logs по умолчанию игнорируются Git; выбранные результаты добавляются осознанно.

# BeerFactory unified frontend

Структура:
- `index.html` — хаб
- `menu.html` — меню
- `training.html` — обучение
- `attestation.html` — аттестация
- `styles.css` — единый дизайн для всех трёх страниц
- `script.js` — единый JS, который определяет страницу через `body[data-page]`

Из страниц вынесены inline `<style>` и `<script>`.
Данные обучения берутся из `training-data.txt`, вопросы аттестации из `questions.txt`.


Актуальная версия меню с двухуровневой фильтрацией и калькулятором заготовок описана в `README-SUBCATEGORIES.md`.

## Copper Brewery Theme v3
Обновлена единая визуальная тема всех страниц: тёмная медь/бронза, тёплые металлические акценты, стеклянные панели и фон мини-пивоварни. Логика меню, NocoDB, субкатегории, обучение, аттестация и калькулятор порций сохранены.

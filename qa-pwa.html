5. Как закрыть offline QA

  1. Сначала онлайн открой портал и эту страницу, дождись PASS по Service Worker и cache.
  2. Включи авиарежим и выключи Wi‑Fi. Нажми «Проверить реальную сеть»: запрос к Worker должен упасть.
  3. Не закрывая эту QA-страницу, нажми «Перезагрузить 390-frame». Портал должен загрузиться из service worker cache.
  4. Внутри frame открой уже закэшированные Dashboard / Recipes / Knowledge. Белого экрана или системной network error быть не должно.
  5. Проверь Shift/Handover: offline-запись не должна выглядеть успешно сохранённой. Для Handover используй текст QA OFFLINE TEST — SHOULD NOT SAVE.
  6. Верни интернет, нажми «Проверить реальную сеть», затем перезагрузи портал. Тестовая offline-запись не должна появиться на сервере.
Не нажимай действия, которые опасно менять в рабочей смене. Для Shift выбирай только безопасную проверку состояния/чекбокса, которую можно сразу сверить после reload.

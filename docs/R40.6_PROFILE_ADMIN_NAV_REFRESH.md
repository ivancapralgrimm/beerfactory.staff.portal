# r40.6: Компактный профиль и управление персоналом

Base branch: `r40.6-attestation-editor`, audited head `ef1ae12debbde1077fd0d7829745f33b6264f916`.

## Что меняется

- `#/profile`: компактный личный кабинет с именем, должностью, правами и двумя пунктами меню.
- `#/profile?view=details`: дата рождения и смена рабочей должности с прежними правилами и сохранением через сервер.
- `#/profile?view=notifications`: прежняя карточка настройки уведомлений на отдельном экране.
- Доступ к управлению персоналом отображается только Owner/Admin.
- `#/admin`: меню из трёх разделов.
- `#/admin?section=team`: команда в компактных сворачиваемых строках, раскрывается только выбранный сотрудник, все прежние действия внутри сохранены.
- `#/admin?section=attempts`: прежние результаты, вопросы и настройки аттестации.
- `#/admin?section=audit`: прежний журнал.
- Переходы участвуют в browser history, работают внутри существующего HashRouter, не требуют изменений в `src/app/App.tsx`.

## Что не меняется

Auth, роли, `src/main.tsx`, Supabase, миграции, логика обновления профиля,
админские действия, результат аттестации, журнал, PWA и deployment.
GitHub Actions пока отложены до работы с компьютера, этот архив workflow не содержит.

## Перед установкой

Загружать только в `r40.6-attestation-editor`. Ожидается ровно 5 файлов:
`src/pages/ProfilePage.tsx`, `src/features/admin/AdminPage.tsx`,
`tests/profile-admin-navigation-r40.6.test.cjs`, `package.json` и данный MD.

Проверить после установки: профиль (включая сохранение должности, дату рождения,
уведомления, выход), доступ Staff/Senior/Owner/Admin; список команды,
раскрытие сотрудника, изменение роли/должности, безопасность/блокировка;
кнопки Аттестации и Журнал; возврат кнопкой телефона/браузера.

## Статус

Синтаксис TSX и новые статические тесты проверены локально.
Полный `npm ci`, `typecheck`, browser QA и Vercel build пока не выполнены,
должны быть проверены после установки. Никаких live-правок в БД.

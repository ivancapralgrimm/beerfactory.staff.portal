# r40.6 Attestation Save Confirmation

Base: `r40.6-attestation-editor` at `63580cadd7a6e428dd26d1f3ab8a175bddd22a87`.

Changes:
- category distribution now says exactly how many questions remain to distribute or remove;
- invalid active-category totals are visually prominent before save;
- after the save RPC, the editor reloads the bank from Supabase;
- success is shown only if pass percent, category counts/labels and ticket plan match the values read back from the server;
- successful confirmation text: `Сохранено на сервере.`;
- failed read-back is surfaced as an explicit error instead of a false success;
- regression tests cover the new behavior.

No database migration, auth, login, recipe, or shift changes.

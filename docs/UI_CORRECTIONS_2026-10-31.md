# Корректировки интерфейса · 31.10.2026

Только локальная сборка Unified RC1. GitHub, production, SQL и базы не изменялись.

- Удалены повторяющиеся подписи об иконках из AppShell, AuthLayout и пивной карты. Атрибуция Streamline Plump Line Free, CC BY 4.0, ссылки на автора/лицензию и отметка об адаптации сохранены внутри закрытого по умолчанию пункта «Лицензии» в настройках.
- В каталоге и редакторе рецептов убран переключатель заведений. Каталог не применяет скрыто старый `place=current`; поиск/категории остаются. Это визуальная фильтрация, серверные права не менялись.
- Базовая высота карточки рецепта 128 → 96 px; миниатюра 88×104 → 68×76. Название 700. Для длинного названия карточка может увеличиваться без обрезки текста; в снимках контрольные высоты 96–108 px.
- Исправлено объявление статического BFGeist как вариативного: подключены реальные локальные начертания 400 и 600, чтобы жирность отображалась в браузере.
- Заведение перенесено в тот же текстовый столбец, непосредственно под должностью в профиле. Имя, должность, заведение и доступ сохраняют свои значения.

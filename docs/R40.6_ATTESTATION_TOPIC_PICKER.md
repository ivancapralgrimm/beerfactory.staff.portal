# BFStaff r40.6 — Attestation Topic Picker Cleanup

## Что входит
- `src/features/attestation/AttestationPage.tsx`
- `tests/attestation-editor-r40.6.test.cjs`

## Что меняется
1. Убрана верхняя фраза `ПРОВЕРКА ЗНАНИЙ`.
2. На её место добавлена кнопка `Назад`, ведущая в `/knowledge`.
3. Блок выбора категории переработан:
   - заголовок теперь `Тестирование по теме: …`
   - ниже один нативный селектор с подписью `Выбери тему`
   - стартовое значение селектора — `…`
   - placeholder `…` отключён и не выбирается вручную
4. Кнопка `Начать` остаётся неактивной, пока тема не выбрана.
5. Нижняя кнопка `К знаниям` убрана со стартового экрана аттестации, так как возврат перенесён наверх.

## Что не меняется
- Логика прохождения теста
- Сохранение результатов
- История попыток
- Экран результата после завершения теста

## Важно
Правка кнопки `Аттестация` на странице `Знания` в этот пакет не входит, потому что исходный файл этой кнопки отсутствовал в локальном наборе дельт. Эту правку лучше делать отдельным коротким архивом по конкретному файлу, чтобы не ломать страницу знаний.

# BFStaff — прозрачные аватары

Все9 существующих аватаров переведены в WebP512 с настоящим alpha-каналом. Удалён только квадратный фон снаружи золотого круга; сам круг, интерьер внутри него и выступающие полотенца/детали сохранены. Это не жёсткая CSS-обрезка по радиусу50%, которая могла бы срезать персонажа.

## Достоверность изображений

ImageGen использован для background-removal mattes. Из его результата взят только alpha: цветовые пиксели нового изображения скопированы из оригинального WebP без перерисовки. Маски приведены к512px и нормализованы2%/97%, чтобы удалить слабые внешние шумы и сделать внутреннюю сцену непрозрачной. Затем CopyOpacity и lossless WebP. Все9 проверены:0 изменённых RGB-пикселей при полностью непрозрачном alpha. Независимый reviewer повторил проверку, сравнил изображения на светлом и тёмном фоне при220/132/60px и подтвердил сохранность лиц, логотипов, кругов и выступающих полотенец.

Оригинальные квадратные файлы сохранены в artwork/staff-avatars/source. Их SHA256 совпадают с первоначальным docs/STAFF_AVATARS_PROVENANCE.json. Маски — artwork/staff-avatars/masks, новая provenance — artwork/staff-avatars/cutout-provenance.json. Опциональное повторное изготовление:node scripts/build-staff-avatar-cutouts.mjs, нужен ImageMagick только для подготовки. Обычная Vercel/PWA-сборка его не запускает и не требует.

## Интерфейс и поведение

На главной и в профиле убраны квадратные CSS backgrounds, border-radius crop и box-shadow. Небольшой drop-shadow на главной следует alpha-силуэту. Габариты не менялись:132px, на узком экране112px; профиль60px. Исходные файлы сохраняют своё обрамление внутри512px canvas, поэтому выступающие детали не вылезают из разметки.

Функция выбора по должности, стабильный вариант1/2, исключительный owner по is_owner и изображения при смене должности не изменялись. Нейтральный fallback остаётся видимым на светлой главной и тёмной карточке профиля. Авторизация, данные, права и серверы не менялись.

Комплект стал больше:2,558,108 байт (2.56MB decimal,2.44MiB), отдельный файл268,518–301,388 байт. Это цена lossless-сохранения исходных цветов. На странице отображается один выбранный файл, повторно используется кэш; все9 входят в PWA precache. Итоговый precache сборки98 entries/3699.27KiB. Реальная скорость на телефоне и offline-установка не объявляются PASS. Исходники/masks из artwork и экспортZIP из docs не попадают в public app assets.

Богатый визуальный момент остаётся в приветственном аватаре; утверждённые пользовательские изображения не удаляются по общему запрету на декоративный3D.

## Product behavior
1. Когда загрузка Ленты успешна **и нет активных записей**, вместо бессмысленной пустоты показывается **одна** системная карточка «BFStaff · Пульс команды».
2. В Dashboard карточка показывается в разделе «Лента» вместо полного исчезновения секции при отсутствии активных записей.
3. **При наличии хотя бы одной активной записи** Dashboard по-прежнему показывает реальные записи, а не «Пульс».
4. На самой странице Ленты «Пульс» показывается **только на вкладке «Активные»**, когда нет активных сообщений. Вкладки «Решённые» и «Все» продолжают показывать реальные записи и корректный empty state.
5. При ошибке сети или загрузки карточка **не подменяет ошибку**: сохраняется существующее сообщение и кнопка повтора.
6. Есть 36 вручную отобранных русских карточек. Выбор детерминирован по операционной дате `Asia/Novosibirsk`; новая карточка в 11:00 местного времени. Смена часового пояса устройства не влияет.
7. В карточке только одно действие: **«Оставить заметку»** (открывает обычную форму Ленты) или **«Заглянуть в знания»** (существующая страница `/knowledge`). Из Dashboard для заметки предусмотрена ссылка `/feed?compose=1`.
8. «Пульс» **не** создаёт записи в `public.notes`, не подменяет сообщения сотрудников, не рассылает push, не собирает отметки «Ознакомился» и не попадает в журнал/аналитику.
9. Исходные операции `createFeedPost`, `acknowledgeFeedPost`, `resolveFeedPost` и все серверные маршруты остаются прежними.

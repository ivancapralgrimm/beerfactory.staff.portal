# Пакет к отдельному разрешению:вход и основные серверные пробелы

Статус:ПРИМЕНЁН после разрешения владельца2026-11-03. Staff-login v9,миграция20261103185831. [Отчёт и откат](../releases/2026-11-03-backend/README.md). Ниже исходный состав одобренного пакета. Общий backend используется и main,и Preview.

2. Применить additive `profile-shift-history.sql` (узкое чтение истории своей текущей должности).
3. Применить `r22-allow-incomplete-position-shift.sql` (сохраняет права,окно смены11:00–03:00НСК,состояния и наличие шаблона;убирает только требование всех галочек).
4. Применить `dashboard-birthday-window.sql` (отвчера до3дней вперёд).
5. Проверить живой первый вход,правильную блокировку неверных данных,историю для разных ролей,смену и дни рождения с разрешённой тестовой учётной записью. В журнале первой попытки не должно быть ложного429 от временного внутреннего401.

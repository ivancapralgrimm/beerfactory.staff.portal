# BFStaff r40.6: компактные результаты аттестации

Основа: `r40.6-attestation-editor` на SHA `97ee97e01c13608d0fa6d0af484aaad635849355`.

## Изменения

- Три счётчика «Попыток / Зачтено / Средний» приведены к тем же классам и размерам, что у счётчиков банка вопросов.
- Полоска категорий с горизонтальной прокруткой заменена одним нативным `<select>` («Все категории» + реальные категории из результатов), адаптированным к мобильным устройствам.
- Удалена избыточная строка «РЕЗУЛЬТАТЫ»; заголовок «Результаты команды» оставлен.
- Логика загрузки результатов, фильтрации, расчёта статистики, даты, навигация и права доступа не изменены.
- В существующий `tests/attestation-editor-r40.6.test.cjs` добавлены три регрессионные проверки. Новых отдельных тестовых файлов или изменений `package.json` нет.

## Установка

Загрузить файлы архива с сохранением путей в **`r40.6-attestation-editor`**, не `main`.
Исходный файл `src/features/admin/AdminAttemptsPanel.tsx` сверялся с GitHub по blob SHA `0e636c77cfc66b2a53a648c4fd077d2d376a726f`.

## Проверка

Открыть «Управление персоналом» → «Аттестации» → «Результаты». Счётчики компактные, единственный селектор категории открывает нативный список выбора на iPhone/Android. При выборе категории показываются только соответствующие попытки, статистика пересчитывается. Строка «РЕЗУЛЬТАТЫ» отсутствует.

Авторизация, Supabase, Edge Functions, миграции и GitHub Actions не тронуты. Последние остаются отложены до работы за компьютером.

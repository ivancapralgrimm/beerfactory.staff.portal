# BeerFactory Staff Portal — субкатегории и калькулятор заготовок

В этой версии меню поддерживает два уровня фильтрации:

- **Бар:** Б/А напитки, Коктейли, Лимонады, Крепкий алкоголь, Вино, Кофе, Чай, Сезонное предложение, Пиво, Бутылочное Пиво, Настойки, Заготовки.
- **Кухня:** Горячие закуски, Холодные закуски, Намазки, Салаты, Супы, Горячие блюда, Гарниры, Соусы, Десерты.

## NocoDB

В таблицах меню используется дополнительное поле:

`Подкатегория`

Ожидаемые поля:

- `Название`
- `Категория`
- `Подкатегория`
- `Теги`
- `Состав`
- `Описание` / `Метод` / `Приготовление`
- `Граммовка` / `Подача` / `Вес`
- `Фото-ссылка`

Для кухни таблица по-прежнему принудительно определяется как `Кухня`, а подкатегория берётся из `Подкатегория`.

Для старых записей сохранена обратная совместимость: старые значения вроде `Коктейли`, `Настойка`, `Пиво`, `Лимонад` автоматически мапятся в `Бар` + соответствующую подкатегорию.

## Карточки

На лицевой стороне карточки теперь показывается только **подкатегория**. Теги не выводятся как подпись карточки.

## Калькулятор

Калькулятор порций включается для:

- `Заготовки`
- `Настойки`

Количество порций задаётся прямо на обороте карточки. Числовые количества в составе пересчитываются автоматически.

Пример:

`Сахар 500гр` → при 3 порциях → `Сахар 1500гр`

Для корректного пересчёта количество должно находиться после названия ингредиента, например `500гр`, `1л`, `100мл`, `2шт`.

## Структура

- `index.html` — хаб
- `menu.html` — меню
- `training.html` — обучение
- `attestation.html` — аттестация
- `styles.css` — общий CSS
- `script.js` — общий JS
- `training-data.json` — материалы обучения
- `manifest.json` — PWA manifest

### Визуальная версия
Текущая сборка оформлена в теме **Copper Brewery v3**: тёмная медь, бронза, тёплые металлические акценты и фон мини-пивоварни. Функциональная логика субкатегорий и калькулятора не менялась.

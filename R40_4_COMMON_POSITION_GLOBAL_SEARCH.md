# BFStaff r40.4 · Common position + Dashboard global search

## Общая позиция

Поле NocoDB `Заведение` теперь имеет три канонических значения:
- `BF`;
- `BB`;
- `BF/BB` — общая позиция.

Legacy/ручное значение `BB/BF` читается так же, как `BF/BB`. Редактор при сохранении всегда пишет `BF/BB`.

Для KITCHEN общая позиция одновременно входит в фильтры:
- `Кухня BF`;
- `Кухня BB`.

В `Все` рецепт отображается один раз. На карточке/в данных рецепта сохраняется признак общей позиции.

## Общий поиск Dashboard

React Dashboard получил эквивалент Product/main global search с новой маршрутизацией:
- рецепты: название, категория, ингредиенты, описание/метод, теги, выход и заведение;
- знания: название, категория, excerpt и текст статьи;
- максимум 8 результатов;
- архивные рецепты помечаются как архив;
- source-aware recipe route `/menu/<bar:id|kitchen:id>`;
- Knowledge route `/knowledge/<articleId>`.

Поиск появляется на Dashboard сразу после hero-блока. Результаты начинают показываться с 2 символов.

## Backend

Для записи общей позиции Worker candidate v5 требует, чтобы в NocoDB `Заведение` был Single Select с choices `BF`, `BB`, `BF/BB`.

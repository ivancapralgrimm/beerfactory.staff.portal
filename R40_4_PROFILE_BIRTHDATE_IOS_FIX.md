# r40.4 Profile birth date iOS fix

Точечная UI-правка поля «Дата рождения».

Причина: iOS Safari может сохранять intrinsic width для `input[type=date]`, даже когда самому input задан `width: 100%` / `max-width: 100%`. Поэтому native control визуально выходил за правую границу карточки.

Исправление:
- рамка и фон перенесены на внешний контейнер строго `w-full`;
- контейнер имеет `overflow-hidden`, поэтому нативная часть Safari физически не может выступить наружу;
- высота поля уменьшена до 40px;
- логика сохранения даты не менялась.

# BeerFactory Staff Portal · Copper Brewery v3

Визуальный апдейт последней рабочей версии Staff Portal без изменения бизнес-логики.

## Что изменено
- Единая тема тёмной меди/бронзы для Hub, Menu, Training и Attestation.
- Добавлен локальный фон мини-пивоварни `brewery-copper-bg.png`.
- Сохранены существующие маршруты: `index.html`, `menu.html`, `training.html`, `attestation.html`.
- Сохранены двухуровневые фильтры Бар/Кухня и все заданные субкатегории.
- Сохранён вывод на карточке только субкатегории.
- Сохранён калькулятор порций для «Заготовки» и «Настойки».
- Сохранена NocoDB-интеграция и поле `Подкатегория`.

## Проверка
- `node --check script.js` — OK.
- `manifest.json` и `training-data.json` — валидный JSON.
- Проверены локальные ссылки/ресурсы HTML — отсутствующих локальных ссылок нет.
- Локальный HTTP smoke test: все основные HTML, CSS, JS, JSON и новый фон отдают HTTP 200.
- ZIP после сборки проверяется через `unzip -t`.

## Самокритично: что НЕ проверено
1. Реальный запрос к NocoDB из этой среды не подтверждён: внешний DNS/сеть ранее были недоступны. Поэтому наличие рабочего токена не считаем доказанным.
2. В архиве нет `questions.txt`. Страница аттестации ожидает этот файл рядом с `attestation.html`, поэтому без него реальные вопросы не загрузятся. Это не проблема CSS, а неполный источник данных аттестации.
3. Визуальный рендер через полноценный браузер в этой среде не был надёжно завершён из-за headless Chromium timeout. Проверка сделана статически и через HTTP smoke test, но это не заменяет ручную проверку на телефоне.
4. На мобильном экране длинный список субкатегорий в боковом меню остаётся прокручиваемым. Это сознательно, иначе 21 пункт превратился бы в UI-лапшу.

## Подключение
Для реального меню в NocoDB должна существовать колонка `Подкатегория` и быть заполнены значения, соответствующие фильтрам.


## Release hardening / исправления

- Исправлены 9 буквальных `\n` в `styles.css`: теперь это реальные переводы строк, включая блок `/* HUB */` и границу перед `/* MENU */`.
- Убран мёртвый первый дубль `.hero-photo` со ссылкой на отсутствующий `images/training/hero.jpg`; активен медный фон `brewery-copper-bg.png`.
- `training.html` больше не содержит ложных захардкоженных счётчиков: числа категорий рассчитываются из `training-data.json`. Пустые категории отключаются до появления материалов.
- В пакет добавлен рабочий `questions.txt` с 15 вопросами для аттестации. Формат соответствует парсеру `script.js`, правильный вариант помечен `*`.
- Запросы к NocoDB получили таймаут 7 секунд, чтобы недоступный внешний API не мог бесконечно подвешивать страницу. При сбое сохраняется локальный fallback.

### Что сознательно не маскируем

- `kitchenTableId` оставлен `mc7m3sa4m2x12dd`, потому что без подтверждения в NocoDB менять ID наугад было бы хуже, чем честный fallback. Перед production нужно сверить ID.
- NocoDB token всё ещё находится в клиентском JS. Это архитектурный риск исходной схемы. Для production правильное решение — прокси/serverless endpoint с секретом на сервере.

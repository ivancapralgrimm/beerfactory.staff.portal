# BeerFactory r40.4 · Dashboard «Что почитать»

Добавляет в нижнюю часть Dashboard горизонтальную подборку статей.

- Заголовок: `Что почитать`.
- На текущей базе знаний выбираются 6 статей.
- Допустимый размер подборки: 4–6.
- Сначала непрочитанные материалы.
- По возможности разные категории до повторов.
- Прочитанные используются только для заполнения подборки.
- Подборка стабильна для сотрудника в течение текущего recommendation day.
- Новый recommendation day начинается в 11:00 по `Asia/Novosibirsk`, как рабочий ритм BFStaff.
- Если активны Birthday/Handover signals, они остаются выше casual-блока.
- Если их нет, блок естественно занимает пустое пространство после основных действий Dashboard.

Карточка содержит категорию, название, время чтения, статус `Прочитано`, а при наличии изображения в статье — первое изображение материала.
Вся карточка открывает существующий Knowledge Article route.

Backend/Supabase не меняются.

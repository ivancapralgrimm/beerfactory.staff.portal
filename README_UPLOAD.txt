BFStaff r40.5 · SQUARE ACTION BUTTONS RESTORE · CUMULATIVE
============================================================

Цель
----
Убрать экспериментальный torn-paper / archival-image вид с квадратных utility/action
кнопок и вернуть их к исходной чистой квадратной UI-системе с небольшой глубиной за
счёт теней.

Что изменено
------------
• Все shared Button size="icon" снова выглядят как обычные компактные квадратные
  кнопки интерфейса, без бумажных/оторванных SVG-подложек.
• Размер touch target: 44×44 px на всех телефонах. Никакой привязки к iPhone.
• Secondary / ghost: светлая кремовая квадратная кнопка, тонкий медно-коричневый
  кант, мягкая внутренняя подсветка и короткая тень.
• Primary / selected: квадратная медно-коричневая кнопка с белой иконкой и лёгкой
  объёмной тенью.
• Danger: квадратная светлая кнопка с красным акцентом.
• Никаких поворотов, скотча, torn edges или image-backed tiles для квадратных actions.
• Нажатие только слегка просаживает кнопку на 1 px и уменьшает тень.
• Focus-visible сохранён отдельным контуром для клавиатурной доступности.

Знания
------
• Компактная строка из sync / карандаш / настройки остаётся.
• Профиль по-прежнему убран.
• Большой заголовок «Знания» сохраняется.
• Все три utility-кнопки теперь обычные квадратные.
• Карандаш «Новая статья» остаётся белым на тёмной медной кнопке.

Что дополнительно откатилось
----------------------------
• Временный глобальный paper-tag override для обычных текстовых Button удалён;
  текстовые кнопки снова используют существующую базовую craft/UI стилизацию.
• Квадратные кнопки в статье, рецептах, смене, чек-листах, ленте, передаче,
  аттестации и админке получают одну и ту же чистую square-систему через shared Button.

Кумулятивность
--------------
Пакет сохраняет уже принятые изменения r40.5:
• checklist editor flow fix без наложения;
• recipe Polaroid / mood-board;
• Knowledge compact toolbar;
• data-craft-size в shared Button для единого управления размерами.

Не менялось
-----------
• API, Supabase, NocoDB, права, роли, маршруты и бизнес-логика.
• main не затрагивался.
• нижний navigation dock не переделывался.

BFStaff r40.5 · ARCHIVAL ICON BUTTONS · CUMULATIVE
=================================================

Цель
----
Заменить детский torn-paper вид квадратных utility/action кнопок по всему порталу
на более взрослый стиль «Архивные карточки», выбранный по визуальному референсу.

Что изменено
------------
• Все shared Button size="icon" продолжают получать единый site-wide стиль через data-craft-size="icon".
• Обычная квадратная action-кнопка: аккуратная кремовая архивная карточка, ровный скруглённый край, фактура бумаги, двойной тонкий кант, мягкая физическая тень.
• Primary / selected квадратная кнопка: чистая кожаная архивная карточка с деликатной внутренней строчкой.
• Иконки на светлой карточке: медно-коричневые.
• Иконки на тёмной кожаной карточке: светлые; карандаш «Новая статья» остаётся белым.
• Danger square action остаётся бумажной карточкой с красным акцентом.
• Никаких рваных краёв в квадратных utility/action кнопках.
• Сохраняются мобильные touch targets: 48 px; 46 px <=390; 44 px <=350.
• Реализация HTML/CSS/SVG, не привязана к iPhone и одинаково рассчитана на iOS Safari/PWA, Android Chrome, Samsung Internet.

Кумулятивность
--------------
Пакет содержит предыдущие r40.5 изменения:
• checklist editor flow fix;
• recipe Polaroid / mood-board;
• Knowledge compact toolbar;
• global Button data-size material system.

Не менялось
-----------
• API, Supabase, NocoDB, права, роли и бизнес-логика.
• main не затрагивался.
• нижний navigation dock сохраняет собственный leather design.

Установка
---------
Загрузить содержимое архива поверх r40.5 с сохранением путей.
Предыдущие cumulative-пакеты отдельно поверх этого ставить не нужно.
